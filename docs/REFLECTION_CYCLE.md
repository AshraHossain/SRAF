# Reflection cycle
Evaluate the draft against task and evidence; critique unsupported claims and missing steps; regenerate under explicit safety tags; re-evaluate until quality gate, iteration limit, no change, or cost ceiling. `max_iterations` counts regenerations, so evaluation calls can be one greater. `improvement_delta = final_score - initial_score`; compare against human labels, not just self-judged score. `approved` indicates a quality gate, not authority to execute external actions. Require an independent human approval token at action time. Scores from the same judge can be biased; run independent blinded evaluation for benchmarks.
